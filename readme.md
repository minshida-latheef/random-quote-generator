\# Daily Spark ✨



A minimal, responsive web app that generates random motivational quotes paired with dynamic background gradients. Built with vanilla HTML, CSS, and JavaScript.



\## Features

\- \*\*Random Quotes:\*\* Cycles through curated quotes without immediate repeats.

\- \*\*Dynamic Gradients:\*\* Changes the background color palette on every click.

\- \*\*One-Click Copy:\*\* Copies the quote and author straight to your clipboard.

\- \*\*Responsive Design:\*\* Clean card layout optimized for desktop and mobile.



\## Getting Started

1\. Clone or download this repository.

2\. Open `index.html` in any web browser.



\## Tech Stack

\- HTML5

\- CSS3 (Flexbox \& Transitions)

\- Vanilla JavaScript (DOM Manipulation \& Clipboard API)
